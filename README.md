# Сборщик информации

Локальное Python-приложение для сбора материалов из настроенных источников и подготовки проверяемых черновиков ежедневной сводки для MAX.

- [Руководство по установке и использованию](./Сборщик%20информации/README.md)
- [Редакционная политика](./Сборщик%20информации/EDITORIAL_POLICY.md)
- [Реестр источников и фильтров](./sources.yaml)

Запускайте команды из папки `Сборщик информации`; источники находятся рядом с ней в `sources.yaml`.
